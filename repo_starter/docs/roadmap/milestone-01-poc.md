# Milestone 01 - PoC

## Goal
Convergere su una PoC giocabile e finibile via Web.

## Deliverable
- core movement
- combat base
- 5 armi
- 2 trasformazioni
- 4 nemici
- boss finale a 2 fasi
- checkpoint a metà
- export Web
- asset visivi e audio coerenti

## Exit criteria
- run completa possibile
- boss sconfiggibile
- feeling duro ma leggibile
- asset abbastanza coerenti da sostenere una demo
