# Prompt - Protagonist

## Base style
2D side-scrolling gothic arcade game, readable silhouette, limited palette, non realistic, gameplay clarity first, moody but playful dark tone

## Prompt
Cursed medieval knight, compact body proportions, rounded armor, side view, strong silhouette, minimal detail, sprite-ready, platform-game readability, theatrical pose, no photorealism, no painterly rendering, no clutter

## Negative
no realism, no over-detail, no cinematic composition, no front-facing pose
