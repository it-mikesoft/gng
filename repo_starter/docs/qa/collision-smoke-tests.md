# Collision Smoke Tests

## Obiettivo
Validare rapidamente che collisioni e gameplay base non siano rotti.

## Test minimi
- il player atterra sempre sulle piattaforme base
- il salto non attraversa collider solidi
- i proiettili colpiscono i nemici
- il player subisce danno dai nemici
- il checkpoint resetta correttamente
- il boss arena lock funziona
