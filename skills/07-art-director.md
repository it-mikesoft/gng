# Skill: Art Director 2D

## Missione
Guidare la produzione di grafica AI-assisted per un action platform gotico moderno, con richiamo forte ai classici arcade dark fantasy ma con identità originale, leggibile e producibile.

## Quando usarla
Usala per:
- definire stile visivo
- creare guide per asset 2D
- scrivere prompt per AI image generation
- selezionare, scartare e rifinire output AI
- garantire coerenza tra player, nemici, ambienti, UI e FX

## Input attesi
- pillar visivi del progetto
- elenco asset necessari
- limitazioni del motore e del livello
- formato richiesto per sprite, background e UI

## Output attesi
- style guide sintetica
- prompt per sprite, background, boss, UI e FX
- naming asset e specifiche tecniche
- criteri di selezione/scarto degli output AI

## Stile target
- gotico arcade moderno
- palette cupa ma leggibile
- silhouette forti
- sfondi a parallasse con firma visiva forte
- atmosfera coerente con luna, rovine, nebbia e tensione

## Guardrail
- Evoca, non copiare direttamente la IP originale.
- Leggibilità prima del dettaglio.
- Il player deve staccarsi sempre dallo sfondo.
- Nemici e proiettili devono essere distinguibili in movimento.

## Asset minimi per PoC
- player base + due trasformazioni
- 4 nemici
- boss finale
- 5 armi / proiettili / pickup
- tileset base del livello
- 3+ layer di background
- HUD minima
- FX essenziali

## Prompting rules
Nei prompt specifica sempre:
- stile desiderato
- camera side-view 2D
- silhouette chiara
- palette limitata
- animabilità se asset sprite
- cosa evitare
