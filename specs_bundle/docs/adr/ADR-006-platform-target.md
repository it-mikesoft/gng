# ADR-006: Target Platform

## Status
Accepted

## Decision
- Target primario: Web
- Target secondario: macOS

## Rationale
- distribuzione rapida
- facilità di testing e condivisione
- minor attrito nelle review della PoC

## Implications
- attenzione a performance, caricamento e memoria
- UI e input devono funzionare bene da browser
- packaging macOS può arrivare in seconda fase
