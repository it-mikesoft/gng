# BDR-005: MVP Scope

## Include
- player completo
- 5 armi
- 2 trasformazioni
- 4 tipi di nemici
- 1 boss finale
- 1 livello
- checkpoint a metà
- export Web
- test unitari
- test di integrazione
- smoke test per collisioni

## Non include
- multiplayer
- progressione meta estesa
- più livelli
- sistema economico
- crafting
- salvataggi complessi

## Nota di perimetro
La PoC deve dimostrare il cuore del gioco, non la completezza del prodotto finale.
