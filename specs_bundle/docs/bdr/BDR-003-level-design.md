# BDR-003: Level Design

## Durata target
- 8–12 minuti per run completa da parte di un giocatore capace
- più tempo per un primo tentativo

## Struttura
- un solo livello completo
- midpoint checkpoint
- restart diretto sul boss finale dopo il checkpoint

## Componenti richieste
- scrolling laterale
- parallasse dinamica
- firma visiva forte
- progressione di tensione crescente
- boss arena distinta dal resto del livello

## Firma visiva della PoC
- luna dominante
- castello gotico sullo sfondo
- alberi secchi, rovine e nebbia

## Principi
- leggibilità prima dell'effetto scenico
- ogni sezione deve avere un ruolo: introduzione, pressione, variazione, climax, boss
